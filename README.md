## Как пользоваться

1) Вход на сайт
   - Перейдите на сайт по `https://deletebadzim.aurorass.art`.

2) Поиск вакансий (`/vacancies`)
   - Заполните поля фильтров на странице и нажмите кнопку поиска.
   - Скопируйте ссылку вакансии, если используете её в адаптации резюме.

3) Адаптация резюме 
   - Перейдите на `/adapt`.
   - Заполните форму резюме 
   - Сервер запросит текст вакансии у SuperJob, сформирует промпт и отправит его модели.
   - Полученный ответ появится в чате; вы будете перенаправлены на `/adapt/iterate` для продолжения работы.

4) Диалоговая сессия
   - Введите в поле чата инструкцию и нажмите "Отправить правку".
   - Повторяйте действия до получения желаемого результата.

5) PDF
   - Когда вас устроило резюме, адаптированное ИИ-модель, напишите промпт из шаблона [static/aireq.txt](static/aireq.txt)
